# MediTech - Medical Records System

A healthcare system to manage medical records and patient workflows.

## 🛠 Tech Stack
- ASP.NET Core Web API
- Redis (for caching)
- JWT Authentication
- Onion Architecture
- SQL Server

## 🔑 Features
- Patient record CRUD
- Doctor & staff user roles
- Appointment scheduling
- Caching with Redis for dashboard performance

## 🚀 How to Run
1. Clone the backend repositories
2. Set DB and Redis configs in `appsettings.json`
3. Run API and Angular project
